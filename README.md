# 桂黄瑞 AI 分身

一个纯前端网页应用：AI 基于你提供的真实 QQ 聊天记录（2022–2026，8640 条对方消息），以「桂黄瑞」本人的说话风格和你聊天。

在线地址：https://ghuar.github.io/guihuangrui-ai/

## 功能

- **人设对话**：AI 严格模仿桂黄瑞——极简短句、爱发"？"、口头禅（真的/笑死/我去/妈呀/不是/啥）、表情三件套 😭👀👊、游戏日常（王者/原神）
- **记忆**：聊天记录自动保存在浏览器 localStorage，刷新、关闭页面都不丢；再次打开自动恢复上下文
- **表情包**：输入框上方有表情面板（高频 emoji + 颜文字），点击即发送；AI 回复也按人设带表情
- **人设开关**：可随时切换"人设模式 / 普通模式"
- **模型可选**：Doubao-Seed 全系，支持自定义模型 ID

## 使用

1. 打开 https://ghuar.github.io/guihuangrui-ai/
2. 右上角「设置」→ 粘贴你的火山方舟 API Key（Key 只保存在当前浏览器本地，不上传任何服务器）
3. 选择模型（默认 Doubao-Seed-2.1-pro）
4. 开始和「桂黄瑞」聊天

## 技术说明

- 单文件 HTML，无后端、无数据库，所有数据（Key、聊天记录、设置）存于浏览器 localStorage
- 调用火山方舟 Ark API（`/api/v3/chat/completions`，流式输出）
- 换浏览器 / 换设备需重新粘贴 Key；聊天记录按浏览器+域名隔离
